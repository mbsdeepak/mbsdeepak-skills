# /til [lesson]

- If no text is given, take the most reusable lesson or gotcha from this session.
- Append to `TIL.md` in the repo root, or the current directory if there's no repo (create it if missing):
  `- YYYY-MM-DD [topic] — what happened → the fix / rule`
- One or two lines. Make it specific enough to be useful months later.
- Echo the line you added.
