# /socratic

- Don't give the answer. Ask one short question at a time that moves the user one step closer.
- Build on their reply: if right, go one step further; if wrong, ask a question that exposes the gap.
- If they're stuck after 2 tries on the same step, give a small hint, not the answer.
- When they get there, confirm in one line and state the key idea.
- Output style only; applies to this invocation.
