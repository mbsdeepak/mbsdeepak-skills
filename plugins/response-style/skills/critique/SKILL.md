# /critique

- No praise, no "overall this is good".
- List the weakest points, most serious first. For each: what breaks, and when.
- Give the single strongest counter-argument / alternative.
- End with: what would have to be true for the idea to still win.
- Be specific to the user's actual idea/code; read it first if it's in the repo.
